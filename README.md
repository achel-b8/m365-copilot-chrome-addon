# Copilot Default Model

Microsoft Copilot で新しいチャットを開いたとき、モデルを「自動」から `GPT 6.0 Sol` へ自動で切り替える Chrome 拡張です。

## インストール

1. Chrome で `chrome://extensions/` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. この `copilot-default-model` フォルダを選びます。
5. すでに Copilot を開いている場合は、そのタブを一度再読み込みします。

## 使い方

Copilot で新しいチャットを開くと、自動的に `GPT 6.0 Sol` が選ばれます。一度自動選択した後は、ユーザーが手動で別のモデルに切り替えても元に戻しません。

自動選択は「チャット」画面だけで動作します。Cowork／タスク画面では、タスク履歴などを誤操作しないよう処理を停止します。

拡張アイコンを押すと、次の操作ができます。

- 自動選択のオン／オフ
- 選択するモデル名の変更
- 現在のチャットですぐに選択処理を再実行

## 対象サイト

- `copilot.cloud.microsoft`
- `m365.cloud.microsoft`
- `microsoft365.com` / `office.com`
- `copilot.microsoft.com`

## プライバシー

この拡張は外部へ通信しません。Copilot の画面上にあるモデル選択メニューを操作し、設定したモデル名とオン／オフだけを Chrome の拡張機能ストレージへ保存します。

## 補足

Copilot の画面構造が変更された場合は自動選択が動かなくなる可能性があります。その場合は拡張アイコンを開き、表示される状態メッセージを確認してください。
